# Modern Expense Tracker

A personal expense tracker that runs entirely in the browser. Add spending, review a month by category, and keep every entry in local storage on the device. There is no account and no server database.

The app is a standard Next.js client, so it can be deployed on Vercel without a backend.

## Scripts

```bash
npm run dev
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000).
